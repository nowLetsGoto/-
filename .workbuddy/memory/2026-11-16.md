# 2026-11-16 · Dandelion 登录功能（前后端打通）

## 目标
给 Dandelion 增加管理员登录，未登录不能上传/发布/看列表，登录后进入包列表页；登录页主题为浅色 + 浅蓝青。

## 后端（Go）
- 契约 `api/openapi.yaml`：新增 `POST /auth/login`、`LoginRequest/LoginResult/LoginResponse`、`401 Unauthorized`、`securitySchemes.bearerAuth`、`x-constants.authTokenTTLSeconds=43200`，以及 `limits.username/password`。
- 新增 `service/auth_service.go`：单管理员账号 + 无状态 HMAC 令牌（载荷只有到期时间戳，`crypto/subtle` + `hmac.Equal` 定长比较），token 形如 `exp.signature`。
- 新增 `handler/auth_handler.go`、`middleware/auth.go`（Bearer 解析 + 401）。
- 路由分组：`POST /builds/stage`、`POST /builds`、`GET /builds` 需登录；`GET /builds/{id}`、`GET /builds/{id}/file`、`/healthz`、静态资源保持公开（扫码下载链路不能挡）。
- 配置新增 `ADMIN_USERNAME` / `ADMIN_PASSWORD` / `AUTH_SECRET`：生产沿用默认密钥 fail-fast。
- `handler.DecodeJSON` 增加 `allowed` 参数（原实现把 commit 的 8 个字段写死在错误文案里）。
- 错误码扩展为 400/401/404/405/413/500：**凭据错误走 400，令牌失效走 401**，前端只需对 401 做统一跳转，不必特判登录接口。

## 前端（React）
- `web/src/pages/login/LoginPage.tsx` + `login.css`：左品牌场（渐变 + 同心圆 + 种子浮动）+ 右极简表单，局部 `--login-*` 变量，移动端单栏。
- `api/session.ts`：localStorage 唯一读写处；`api/auth.ts`：登录调用；`client.ts`：注入 Bearer，401 时清会话并整页跳 `/login`。
- `App.tsx`：`RequireAuth` + layout route（`<Layout><Outlet/></Layout>`）；`/d/:id` 公开；`Layout` 增加账号区与退出（无会话时不渲染）。

## 验证
- `go vet ./...`、`go test ./...` 全过（新增 `auth_service_test.go` 覆盖错误凭据/签发/篡改/换密钥/过期）。
- `tsc --noEmit && vite build` 通过。

## 踩坑与经验
- 登录页表单用 `opacity` 入场动画，截图若不等动画结束会拍到半透明，需 `waitForTimeout(900)`。
- 移动端 Grid（`min-height:100dvh`）的自动行会拉伸第一行，把品牌栏撑到 1/4 屏，必须 `grid-template-rows: auto 1fr`。
- 12px 辅助文字用 `#526d78`，在 `#fbfeff` 与品牌底色上都 ≥4.5:1。
