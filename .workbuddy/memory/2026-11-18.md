## 多租户重构 P1 数据隔离（实施完成）

### 核心机制
- `repository/filter.go` 新增 `ScopeFilter`/`ApplyTenant`/`AddRaw`：scope → SQL 条件。三规则：超管不加条件 / 公司账号限定 tenant_id / 无公司非超管 `1=0` 失败关闭。
- service 从 ctx 取 scope 传仓储（handler 零改动）；authz 身份解析路径（PersonID、resolveRoleKey 查人）显式传 `Scope{All:true}` 避免循环依赖。
- 写入 tenant_id 一律从 scope 取；关联表用 `INSERT ... SELECT ... WHERE tenant_id=$3::uuid` 挡跨租户。
- 公开下载 /builds/{id} 不加 scope；包隔离点在 BuildService.resolveProject → project.FindByKey 带 scope。

### 关键决策
- P1 只做公司级隔离，团队级留 P2（存量成员无团队关联，按 team_ids 过滤会全空）。
- 存量回填提前到 P1（原 P6）：建默认公司 11111111-1111-4111-8111-111111111111，存量账号/人员/团队/项目/角色全归入；admin 超管保持无公司。
- 审计写 tenant_id、查按 tenant 过滤；/admin/audit-logs 仍 RequireSuperAdmin（平台管理员访问留 P3/P5）。

### 踩坑（重要）
1. `INSERT ... SELECT $1, id` 里纯常量投影参数 PG 无法推断类型 → 必须写 `$1::uuid`。
2. `tenant_id = $3::uuid OR $3 = ''` 中同一参数被两种类型解释 → 空串被当 uuid 解析报错。写入必须 tenant_id 非空，去掉 OR 分支。
3. UPDATE 占位符错位：SET 若用 $2..$7（$1 未用），filter base 要按实际占用算，否则参数错位报 could not determine data type。改成 SET 用 $1..$6 + filter base=6。

## 多租户重构 P3 角色与权限下放（实施完成）

### 权限目录精简
- contract.Permissions 只留业务点：build.read/write/delete、project.read/write、directory.read。
- 移除 directory.write、settings.read/write、admin.access；用 contract.Permission* 常量保留（供 managementPermissions 与存量清理）。
- IsValidPermission 只认目录内，所以角色接口无法写入管理点（伪造 400）。
- allPermissions() = 目录 + 四个管理点（否则精简后超管丢能力）。

### 角色租户隔离（关键约束）
- roles.key 全局唯一且被 people.role_key / projects.role_key 外键引用，**不能改复合唯一**。
- 方案：内置角色 tenant_id IS NULL（平台共享、只有超管能改）；自定义角色 tenant_id=公司；**自定义 key 必须带公司 UUID 前 8 位前缀**（避免冲突+可读）。
- 可见性不能用 ApplyTenant（会滤掉 NULL 行，内置角色靠 NULL 表示共享）→ 单独 visibleFilter（条件 `(tenant_id IS NULL OR tenant_id = $1)`，无公司时 1=0）。
- FindByKeyAny 供 authz 权限判定链路用（身份解析不能依赖 scope）。
- roleKeyPattern 放宽为字母或数字开头（UUID 前缀可能数字开头）。

### 路由与人员角色分配
- 角色管理从 RequireSuperAdmin 改为 RequireMinLevel(platform_admin) + RequireTeamMode；团队管理员不进该组。
- people 的 Create/Update 角色校验从 IsSuperAdmin 改为 canAssignRole(team_admin 及以上)；登录名变更仍限超管。

### 存量自愈（重要）
P1 回填把所有角色（含内置）归到默认公司，导致其他公司看不到内置角色。启动执行 NormalizeBuiltins：内置行 tenant_id 归 NULL + 清非超管角色的管理点残留（project-owner 曾有 directory.write）。幂等。
