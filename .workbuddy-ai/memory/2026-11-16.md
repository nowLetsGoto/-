## 前端工程化配置补齐（ESLint + Stylelint + Prettier + husky + lint-staged）

- 需求：把项目规范里要求但一直缺失的前端 lint/format 能力落地，用户选择性确认了这套组合。
- 安装：`npm install --legacy-peer-deps -D eslint@^9 @eslint/js@^9 typescript-eslint@^8 eslint-plugin-react-hooks@^6 eslint-plugin-react-refresh@^0.4 globals@^15 eslint-config-prettier@^9 stylelint@^16 stylelint-config-standard@^36 prettier@^3 husky@^9 lint-staged@^15`。

- 新增配置：
  - `web/eslint.config.js`：flat config，js recommended + tseslint recommended + react-hooks flat/recommended + react-refresh(warn) + prettier 收尾。关掉 `no-undef`（交给 TS）与 `@typescript-eslint/prefer-as-const`（现有 `'' as ''` 写法）。忽略 `src/api/schema.d.ts`（生成物）。
  - `web/.stylelintrc.json`：继承 stylelint-config-standard，关掉与现有 CSS 风格冲突的 11 条纯偏好规则（color-hex-length / value-keyword-case / media-feature-range-notation / 各种 empty-line-before 等），保证基线全绿。
  - `web/.prettierrc.json` / `.prettierignore`、`web/.stylelintignore`。
  - `web/.husky/pre-commit`：`cd web && npx lint-staged`。
- package.json scripts：`lint` / `lint:fix` / `format` / `format:check` / `prepare`；`lint-staged` 配置为 ts/tsx → eslint --fix + prettier --write，css → stylelint --fix + prettier --write。
- **关键坑：husky v9 要求 cwd 有 `.git`，但 git 根在 `web/` 的上一级**。解法：prepare 写成 `cd .. && husky web/.husky`，core.hooksPath 被设为 `web/.husky/_`。CI/无 .git 环境会 gracefully skip。husky 的 `_/` 自带 `.gitignore` 内容 `*`，只有 pre-commit 入库。
